# RAPBATTLE

Live freestyle rap battles: **Gemini** writes the bars, **ElevenLabs** voices them, an AI judge picks a winner after 3 rounds.

## Stack

- `frontend/` — Vite + React + TypeScript
- `functions/` — Firebase Functions (Express) + SSE battle orchestrator
- Firebase Hosting + project `rapbattle-e6ae7`
